# alt通信簿

Webページを閲覧しながら、画像がスクリーンリーダーにどう伝わるかを「良い・普通・悪い」の3択で評価し、記録するChrome拡張機能（Manifest V3）です。

評価の対象は、alt属性を中心にした画像のアクセシブルネーム（スクリーンリーダーが読み上げる名前）です。評価モードをオンにすると、ページ内の各画像の直後に評価ボックスが表示され、その場で評価できます。

企画の詳細は [docs/proposal.md](docs/proposal.md) を参照してください。

## 開発

テストと検査には Node.js が必要です。拡張機能そのものは npm のパッケージを使いません。

```bash
npm install
```

```bash
npm test
```

```bash
npm run check
```
